Set up the rollover

Rollover betting is a lottery-shaped bet with a small, real edge bolted on. Never stake money you cannot lose.

Engine settings

On the edge floor. Counter-intuitively, raising it usually makes a rollover worse. Positive-edge legs are disproportionately longshots, so a hard floor starves the pool of the short prices needed to build a 2.00 accumulator — the day quietly degrades into one long leg. The Lab measured the engine at 53.7% a day with the floor at 0, and multi-leg coverage collapsing when it was raised. The win-probability optimiser lands on +EV legs anyway (around +1.5pp of edge per leg, unprompted), so leave this at 0 and read it as a reporting number rather than a gate. The builder relaxes it in tiers and tells you which tier it used.

Settings apply to every new scan and run. Existing runs keep the settings they were created with.
